1. OVERVIEW
================================================================================

Each Plan now has a set of granular permissions stored in a PlanPermissions
join table. Endpoints are guarded by [RequirePlanPermission] which returns
403 if the clinic's active plan doesn't include the required permission.

The old [RequireSubscription] (binary on/off) has been replaced with
[RequirePlanPermission] throughout the API.

4. CHECKING USER PERMISSIONS ON THE FRONTEND
================================================================================

  4a. From JWT (Current)
  ────────────────────────

  The JWT still has only the binary HasActiveSubscription claim.
  It does NOT contain individual permission claims.

    const decoded = jwtDecode(token);
    const hasSubscription = decoded.HasActiveSubscription === 'True';
    // This tells you they have SOME subscription, not WHICH permissions.

  Use this only for the initial app-level gate (show/hide dashboard).
  For granular feature gating, use option 4b.

  4b. From Dedicated Permissions Endpoint (Recommended)
  ────────────────────────────────────────────────────

  Fetch the active subscription once on app load / login and cache
  the permissions array:

  async function fetchMyPermissions() {
    const token = localStorage.getItem('accessToken');
    const res = await fetch('/api/v1/subscriptions/my', {
      headers: { Authorization: `Bearer ${token}` }
    });
    const body = await res.json();
    const permissions = body.data?.permissions ?? [];
    localStorage.setItem('myPermissions', JSON.stringify(permissions));
    return permissions;
  }

  Then check permissions anywhere:

  function hasPermission(permissionName) {
    const perms = JSON.parse(localStorage.getItem('myPermissions') || '[]');
    return perms.includes(permissionName);
  }

  // Usage
  if (hasPermission('AdvancedReports')) {
    // Show advanced reports button
  }

  4c. Permission Names Reference
  ──────────────────────────────

  The API returns permissions as string names (not integer values):

5. GATING UI ELEMENTS
================================================================================

  5a. Hide/Show Features by Permission
  ─────────────────────────────────────

  // React example
  function AdvancedReportsButton() {
    const [canAccess, setCanAccess] = useState(false);

    useEffect(() => {
      const perms = JSON.parse(localStorage.getItem('myPermissions') || '[]');
      setCanAccess(perms.includes('AdvancedReports'));
    }, []);

    if (!canAccess) return (
      <Tooltip title="Upgrade to Standard or Premium to access this feature">
        <button disabled onClick={() => showUpgradeModal()}>
          Advanced Reports ⭐
        </button>
      </Tooltip>
    );

    return <button onClick={openReports}>Advanced Reports</button>;
  }

6. UPGRADE FLOW
================================================================================

  Current plan is Basic, user wants Advanced Reports:

  1. User clicks locked "Advanced Reports" card
  2. Show upgrade modal with required plan info
  3. User clicks "View Plans & Upgrade"
  4. Navigate to /plans (or /subscriptions/upgrade)
  5. Show plans with current plan highlighted and "Upgrade" CTA
  6. User selects new plan → calls backend
  7. Backend: we need to handle plan change/upgrade endpoint

  (Note: The plan upgrade endpoint is not yet implemented in the backend.
   Currently, the user would cancel their subscription and subscribe to
   a new plan. A future enhancement could add a dedicated upgrade endpoint
   that prorates the remaining balance.)

7. ERROR HANDLING
================================================================================

  When [RequirePlanPermission] denies access, the API returns:

  HTTP 403
  {
    "success": false,
    "message": "Your current plan does not include this feature. Please upgrade to access it.",
    "data": null,
    "statusCode": 403
  }

  Frontend handling:

  async function apiCall(url, options) {
    const res = await fetch(url, options);
    if (res.status === 403) {
      const body = await res.json();
      if (body.message?.includes('plan does not include')) {
        // Permission denied — show upgrade prompt
        showUpgradePrompt();
        return null;
      }
      if (body.message?.includes('subscription required')) {
        // No active subscription at all
        window.location.href = '/subscription-required';
        return null;
      }
    }
    return res.json();
  }
