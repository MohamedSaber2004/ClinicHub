You are working on the ClinicHub ASP.NET Core backend, a Clean Architecture (Domain / Application / 
Infrastructure / Persistence / API) project using CQRS with MediatR. The project already has a

─── STEP 3: Infrastructure Layer ────────────────────────────────────────
FILE: ClinicHub.Infrastructure/Services/Paymob/PaymobService.cs  (MODIFY)
Implement InitiateDisbursementAsync() using Paymob's Disbursement API:

  Paymob Disbursement endpoint: POST https://accept.paymob.com/api/disbursement/create
  Auth: use _settings.DisbursementApiKey (separate from collection SecretKey)

  For BankTransfer, the request body is:
  {
    "amount": <amountCents>,          // amount * 100
    "currency": "EGP",
    "type": "bank_card",             // use "bank_card" for IBAN bank transfers in Egypt
    "recipient_name": "<name>",
    "iban": "<IBAN>",
    "description": "ClinicHub appointment payout - <payoutId>",
    "reference_id": "<payoutId>"     // your internal Payout entity ID for traceability
  }

  For MobileWallet, the request body is:
  {
    "amount": <amountCents>,
    "currency": "EGP",
    "type": "mobile_wallet",
    "phone": "<walletNumber>",        // must be in format 01XXXXXXXXX
    "recipient_name": "<name>",
    "description": "ClinicHub appointment payout - <payoutId>",
    "reference_id": "<payoutId>"
  }

  Parse the JSON response:
  - Success: response.status == "success" or response.disbursement_id is not null
  - Return PayoutResultDto { DisbursementId = response.disbursement_id, Success = true }
  - On HTTP error or failure status: return PayoutResultDto { Success = false, FailureReason = ... }
  - IMPORTANT: wrap in try/catch and never let exceptions bubble up to the webhook handler
