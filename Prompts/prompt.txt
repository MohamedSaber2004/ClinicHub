The two pages show data from different backend endpoints — they're not the same records:
- Appointments page → GET /staff/appointments → returns ALL appointment bookings (statuses: pending, confirmed, cancelled, completed)
- Queue page → GET /staff/queue → returns the clinic WAITING ROOM (statuses: registered, waiting, in-progress, completed)
A single patient's journey: Appointment: confirmed (booking approved) → Queue: waiting (checked into clinic) → Queue: in-progress (seeing doctor) → Queue/Appointment: completed.
So having "مؤكد" on the Appointments page and "في الانتظار" on the Queue page for the same patient is correct behavior — they show different stages. They are usually different patients too (appointments show all bookings, queue shows only patients currently in the clinic).
If you want them to match, you'd need the backend queue endpoint to only return items whose appointment status matches a certain criteria — but that's a backend concern, not a frontend bug.
