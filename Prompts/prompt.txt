## 1. GET `/dashboard/stats`

Returns clinic operational statistics with period breakdowns.

### Response `200 OK`

```json
{
  "todayVisits": 45,
  "todayIncome": 1450.0,
  "weeklyVisits": 280,
  "weeklyIncome": 8500.0,
  "monthlyVisits": 1200,
  "monthlyIncome": 36000.0,
  "yearlyVisits": 15400,
  "yearlyIncome": 468000.0,
  "pendingActions": 5
}
```

### Response Fields

| Field | Type | Description |
|---|---|---|
| `todayVisits` | `int` | Number of patient visits today |
| `todayIncome` | `double` | Total income today (EGP) |
| `weeklyVisits` | `int` | Number of patient visits this week |
| `weeklyIncome` | `double` | Total income this week (EGP) |
| `monthlyVisits` | `int` | Number of patient visits this month |
| `monthlyIncome` | `double` | Total income this month (EGP) |
| `yearlyVisits` | `int` | Number of patient visits this year |
| `yearlyIncome` | `double` | Total income this year (EGP) |
| `pendingActions` | `int` | Count of pending booking requests (shortcut for UI badge) |

### Business Rules

- All periods are calculated based on the clinic's local timezone.
- "week" starts on Monday 00:00:00.
- "month" and "year" are calendar-based.
- `pendingActions` should equal the count of bookings where `status == "pending"`.
