
  To ensure that payment processing dynamically works across Local Dev (localhost), Staging, and Production, changes were implemented
  in both the frontend initiation flow and the result page.
  ──────
  ### What Was Updated:

  1. **InitiatePaymentRequest.cs**:
  Added ReturnUrl property to InitiatePaymentRequest.
  2. **ClinicController.cs**:
  Dynamically generates the frontend return URL based on the current active request host (Request.Scheme://Request.
  Host/Home/PaymentResult) and sends it to the backend API:
      • On Local Dev: https://localhost:44339/Home/PaymentResult
      • On Production: https://your-domain.com/Home/PaymentResult
  3. **PaymentResult.cshtml**:
      • Renders the payment outcome.
      • Runs a 5-second countdown timer.
      • Uses dynamic browser origin (window.location.origin + '/') to redirect the user back to the base URL of whichever environment
      they are currently operating in.
